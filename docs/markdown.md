# Markdown

Правила разметки проверяются линтером `markdownlint-cli2` с конфигурацией `.markdownlint-cli2.yaml`.

| Правило | Требование |
| --- | --- |
| MD003 | Заголовки в стиле ATX: `# Заголовок` |
| MD004 | Маркер списка — дефис `-` |
| MD007 | Отступ вложенного списка — 4 пробела |
| MD013 | Длина строки не ограничена |
| MD029 | Нумерация списка по порядку: 1, 2, 3 |
| MD040 | У блока кода указан язык |
| MD050 | Полужирный через звёздочки: `**текст**` |

## Пример блока кода

```bash
npx markdownlint-cli2 "**/*.md"
```
