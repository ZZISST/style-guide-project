# Оформление текста

## Заголовки

- Пишите заголовки с прописной буквы, остальные слова — со строчной.
- Не пропускайте уровни заголовков.

## Списки

- Используйте маркированный список, если порядок не важен.
- Используйте нумерованный список для последовательных шагов.
- Начинайте пункты с прописной буквы.

## Выделение

- **Полужирный** — названия элементов интерфейса.
- *Курсив* — термин при первом упоминании.
- `Моноширинный` — код, команды, имена файлов.
