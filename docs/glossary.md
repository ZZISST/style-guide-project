# Глоссарий

| Термин | Определение |
| --- | --- |
| Docs as Code | Подход, при котором документация ведётся как код: в Git, с ревью и CI |
| PR (pull request) | Запрос на слияние изменений из ветки в основную |
| CI | Непрерывная интеграция: автоматические проверки при каждом изменении |
| Линтер | Программа, которая проверяет текст на соответствие правилам |
| Стайлгайд | Свод правил оформления документации |
