# Доступность текста

Документация должна быть понятна всем читателям, в том числе тем, кто пользуется экранным диктором или читает с увеличением.

## Структура

- Соблюдайте иерархию заголовков: после `#` идёт `##`, без пропусков уровней.
- Разбивайте длинный текст на короткие абзацы и списки.

## Изображения

- Добавляйте к каждому изображению альтернативный текст: `![Схема деплоя](deploy.png)`.
- Не передавайте информацию только цветом: дублируйте её текстом или значком.
- Не размещайте важный текст только на скриншоте.

## Ссылки

- Пишите понятный текст ссылки: «[инструкция по установке](index.md)», а не «нажмите здесь».

## Таблицы

- У каждой таблицы должна быть строка заголовков.
- Не используйте таблицы для вёрстки.

## Язык

- Пишите простыми словами, расшифровывайте аббревиатуры при первом упоминании.
