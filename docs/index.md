# Стайлгайд документации

Стайлгайд описывает правила, по которым мы пишем техническую документацию: тон, орфографию, оформление текста и разметку Markdown.

Документация ведётся по методологии Docs as Code: исходники лежат в Git, изменения проходят через pull request и ревью, а сайт собирается и публикуется автоматически.
