# Как запустить notify-service локально

Инструкция описывает, как запустить сервис уведомлений notify-service на своём компьютере для разработки и отладки.

## Перед началом

- Установите Go 1.22 или новее.
- Установите Docker 24 или новее.
- Склонируйте репозиторий сервиса:

```bash
git clone https://github.com/<организация>/notify-service.git
```

Где `<организация>` — имя организации на GitHub, в которой лежит репозиторий.

## Подготовить конфигурацию

1. Перейдите в папку сервиса и скопируйте пример конфигурации:

    ```bash
    cd notify-service
    cp .env.example .env
    ```

2. Откройте файл `.env` и укажите значения переменных:

    ```bash
    DATABASE_URL=postgres://<пользователь>:<пароль>@localhost:5432/notify
    SMTP_HOST=<адрес-smtp-сервера>
    ```

    Где:

    - `<пользователь>` и `<пароль>` — учётные данные локальной базы данных;
    - `<адрес-smtp-сервера>` — адрес тестового SMTP-сервера, например `localhost:1025`.

## Запустить сервис

1. Запустите базу данных:

    ```bash
    docker compose up -d postgres
    ```

2. Запустите сервис:

    ```bash
    go run ./cmd/notify-service
    ```

    Сервис выведет сообщение о запуске:

    ```text
    INFO notify-service started on :8080
    ```

## Проверка результата

Отправьте запрос к методу проверки состояния:

```bash
curl http://localhost:8080/health
```

Сервис вернёт ответ:

```text
{"status":"ok"}
```

## Возможные проблемы

| Ошибка | Причина | Что сделать |
| --- | --- | --- |
| `connection refused` при запуске | База данных не запущена | Выполните `docker compose up -d postgres` |
| `address already in use` | Порт 8080 занят другим процессом | Укажите другой порт в переменной `HTTP_PORT` |
| `DATABASE_URL is required` | В файле `.env` нет строки подключения | Заполните `DATABASE_URL` в файле `.env` |
